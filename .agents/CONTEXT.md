## 2. Core Architectural Invariants

- **Stack (locked):** Next.js `14.2.21`, React `18.3.1`, TypeScript, Tailwind `3.4.17`, Supabase (`@supabase/supabase-js`, `@supabase/ssr`), grammY `1.34`, Recharts `2.15.4`, Radix UI primitives, Lucide icons, Zod, Vitest, Playwright `1.49.1`.
- **Auth & Tenancy:** Supabase Auth (`getUser()` in `lib/auth/session.ts` and `app/(platform)/layout.tsx`; `middleware.ts` currently uses `getSession()` — queued for Phase L). All writes go through the service role (`createAdminSupabaseClient()` wrapped in `fromWithEarlyFilters` via `asDbClient()`). `tenant_id IS NULL` represents the owner store; resellers have a `tenants` row (`owner_user_id = auth.uid()`). Tenant scope always comes from the session/API key, never request bodies.
- **Database Write Safety (`lib/supabase/query.ts`):** `fromWithEarlyFilters` buffers filters set before `select/update/delete/upsert` and refuses any write (`update`/`delete`/`upsert`) with no row filter (`Refusing a write with no filter.`).
- **Money (ADR 1 & 2):** USDT-only, `bigint` minor units (`1 USDT = 1,000,000`) via `lib/money.ts`. BSC BEP20 USDT has 18 decimals (`raw / 10^12` via `usdtRawToMinorUnits`). Reseller wallets mutate ONLY through Postgres `SECURITY DEFINER` RPCs (`0004_wallet_functions.sql`) writing append-only `ledger_transactions`. Buyer credit is `customers.credit_balance`, mutated atomically via `pay_order_from_customer_wallet` (`0024`), `credit_wallet_topup` (`0029`), `redeem_points_to_wallet` (`0028`), and `adjust_customer_credit` (`0012`).
- **Order State Machine (ADR 6, `modules/orders/state-machine.ts`):** Four independent tracks (`payment_status`, `funding_status`, `fulfillment_status`, `delivery_status`) + append-only `order_events`. Delivered (`sent`) has no outgoing transition; owner replacement buys a new supplier item or sends manually (`modules/platform/replacements.ts`). Never add a buyer Replace button in Telegram.
- **Visual System:** Near-black `#0b0709` (`data-theme="dark"`, theme version 3), 6-glow mesh, rose glass sidebar (`256px`), glass cards (`blur 22px`), opaque `.surface-table`, Outfit + JetBrains Mono, rose `#ff5f8f` primary, amber `#f2b23e`, sky `#7ea6ef`, mint `#4fdc9c`, danger `#ff5a5f`, violet `#a98bff`. Shared UI kit lives in `components/platform/ui/`.

## 8. Known Gaps & Risks to Track (Phases F–O)

- **Fraud rule mismatch:** `modules/platform/fraud.ts` still counts all orders (not just unpaid) and blocks checkout via `assertCustomerAllowed(..., 'order')` in `modules/orders/index.ts:118`, conflicting with "never block a paying customer"; 0034 freebie/discount caps are not yet enforced there.
- **BEP20 confirmations / top-up expiry:** `/payments` displays `15` from `bep20MinConfirmations()` (`integrations/bsc/verify.ts`, env `BEP20_MIN_CONFIRMATIONS`, default `15`), NOT from any DB column. `0035` adds `platform_settings.bep20_confirmations default 12` and `topup_expiry_minutes default 60`, neither of which is wired into `verify.ts` or `modules/topups/*` yet.
- **Phase E Settings loose ends:** `PolicyForm` per-store override is hardcoded to `stores[0]` and `assertResellerFieldsAllowed` does not yet read `tenants.reseller_policy_override`; `DangerForm` resets `goalUsdt` to `'0'`; `PaymentsForm`/`NotificationsForm`/`PricingForm`/`StoreForm` do not hydrate several saved fields on GET; `PATCH` payments uses `Math.round(x * 1_000_000)` instead of `usdtToMinor`; legacy `/reseller/settings/api-keys` redirects to `?section=api-keys` instead of `?section=keys`; Hindsight check reads `HINDSIGHT_BASE_URL` instead of `HINDSIGHT_API_URL`.
- **Bots page loose ends:** Pausing the owner bot writes `owner_bot_status = 'paused'`, violating the `0013` CHECK constraint (`connected|disconnected|error`); disconnecting the owner bot skips `disconnectOwnerBot()`; "Re-set webhook" on `/bots` always calls `POST /api/platform/store` (reconnects owner bot even on reseller cards); `role` detection on `/bots` assumes a row with `id === 'owner'` is present.
- **Bot Studio preview images:** `modules/platform/store.ts:138` constructs `/storage/v1/object/public/product-previews/...`, but `product-previews` is a private bucket (`0003`).
- **Git hygiene:** `.cursor/design-reference/` is not in `.gitignore` (never commit it). 21 unpushed commits carry Cursor `Co-authored-by` trailers that must be stripped before any push. `scripts/sql/fresh-start.sql` has fixes scheduled for Phase N.
