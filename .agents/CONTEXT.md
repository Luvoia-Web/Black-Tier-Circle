## 2. Core Architectural Invariants

- **Stack (locked):** Next.js `14.2.21`, React `18.3.1`, TypeScript, Tailwind `3.4.17`, Supabase (`@supabase/supabase-js`, `@supabase/ssr`), grammY `1.34`, Recharts `2.15.4`, Radix UI primitives, Lucide icons, Zod, Vitest, Playwright `1.49.1`.
- **Auth & Tenancy:** Supabase Auth (`getUser()` via `lib/auth/verify-user.ts` with transient transport-error retry in `middleware.ts`, `lib/auth/session.ts`, and `app/(platform)/layout.tsx`; fail-closed on real auth/profile errors). All writes go through the service role (`createAdminSupabaseClient()` wrapped in `fromWithEarlyFilters` via `asDbClient()`). `tenant_id IS NULL` represents the owner store; resellers have a `tenants` row (`owner_user_id = auth.uid()`). Tenant scope always comes from the session/API key, never request bodies.
- **Database Write Safety (`lib/supabase/query.ts`):** `fromWithEarlyFilters` buffers filters set before `select/update/delete/upsert` and refuses any write (`update`/`delete`/`upsert`) with no row filter (`Refusing a write with no filter.`).
- **Money (ADR 1 & 2):** USDT-only, `bigint` minor units (`1 USDT = 1,000,000`) via `lib/money.ts`. BSC BEP20 USDT has 18 decimals (`raw / 10^12` via `usdtRawToMinorUnits`). Reseller wallets mutate ONLY through Postgres `SECURITY DEFINER` RPCs (`0004_wallet_functions.sql`) writing append-only `ledger_transactions`. Buyer credit is `customers.credit_balance`, mutated atomically via `pay_order_from_customer_wallet` (`0024`), `credit_wallet_topup` (`0029`), `redeem_points_to_wallet` (`0028`), and `adjust_customer_credit` (`0012`).
- **Order State Machine (ADR 6, `modules/orders/state-machine.ts`):** Four independent tracks (`payment_status`, `funding_status`, `fulfillment_status`, `delivery_status`) + append-only `order_events`. Delivered (`sent`) has no outgoing transition; owner replacement buys a new supplier item or sends manually (`modules/platform/replacements.ts`). Never add a buyer Replace button in Telegram.
- **Visual System:** Near-black `#0b0709` (`data-theme="dark"`, theme version 3), 6-glow mesh, rose glass sidebar (`256px`), glass cards (`blur 22px`), opaque `.surface-table`, Outfit + JetBrains Mono, rose `#ff5f8f` primary, amber `#f2b23e`, sky `#7ea6ef`, mint `#4fdc9c`, danger `#ff5a5f`, violet `#a98bff`. Shared UI kit lives in `components/platform/ui/`.
